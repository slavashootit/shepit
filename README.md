# Шепіт

Нативний голосовий диктант для **macOS на Apple Silicon** (`M1`–`M4`). Натискаєте правий `Option (⌥)`, говорите живою мовою — за чверть секунди текст уже вставлено в активне поле чату, редактора чи нотаток.

**[Сторінка проєкту та жива демонстрація →](https://slavashootit.github.io/shepit/)** · **[Завантажити `.dmg` (Apple Silicon) →](https://github.com/slavashootit/shepit/releases/latest)**

---

## Швидке встановлення (за 15 секунд)

Виконайте в Терміналі одну команду — вона поставить `/Applications/Шепіт.app`, автоматично зніме карантин macOS Gatekeeper і відкриє програму:

```bash
curl -fsSL https://slavashootit.github.io/shepit/install.sh | zsh
```

Або завантажте образ **[`Shepit-AppleSilicon.dmg`](https://github.com/slavashootit/shepit/releases/latest/download/Shepit-AppleSilicon.dmg)** і перетягніть **«Шепіт»** у теку `Applications`.

Після першого запуску:
1. Дозвольте доступ до **Мікрофона** та **Доступності** (`Accessibility` — для миттєвої авто-вставки тексту).
2. Відкрийте вкладку **«Моделі»** та натисніть **«Встановити локальну модель (~2,34 ГБ)»** — програма сама підготує середовище Apple MLX і завантажить ваги офлайн-моделі.

---

## Чому «Шепіт»

- **Миттєвий офлайн на Apple GPU (`Parakeet TDT 0.6B v3` через MLX):** модель постійно тримається гарячою в пам'яті. Розпізнавання репліки займає ~`0,25 с` без інтернету та без підписок (25 мов, включно з українською й англійською).
- **Розумна автопідстраховка брендів (`Groq Whisper Large v3`):** якщо підключити безкоштовний ключ Groq, гібридний режим підстраховує лише ті фрази, де локальна модель засумнівалась у слові або почула іноземну назву продукту.
- **Подвійний режим правого `Option (⌥)`:**
  - **Утримання (`Push-to-Talk`):** тримаєте `Option` — записує, відпускаєте — вставляє текст.
  - **Короткий тап (`< 280 мс`):** вмикає запис **«Без рук»** для довгих думок; повторний тап завершує запис, `Esc` — скасовує.
- **Не «глухне» після сну Мака:** кожен запис відкриває свіжу сесію `AVAudioEngine` на живому `AudioDeviceID` (коректно переживає сон ноутбука, зміну AirPods і зовнішніх USB-мікрофонів), а глобальний `CGEventTap` сам відновлюється після системних таймаутів.
- **Режими ШІ, словник та історія:**
  - Режими **«Голос у текст»**, **«Чиста думка»** (прибирає слова-паразити й обмовки) та **«Переклад англійською»** (`⌥⇧K`), а також прив'язка режимів до конкретних програм.
  - Власний словник термінів і миттєві автозаміни.
  - Повна локальна статистика (слова, WPM, зекономлений час, активність по програмах) і пошук по історії в SQLite (`~/Library/Application Support/Shepit/`) із можливістю переслухати запис або перерозпізнати аудіофайл перетягуванням у вікно.

## Збірка з вихідного коду

Потрібен Mac на Apple Silicon (`macOS 14 Sonoma` або новіша) і встановлені `Xcode Command Line Tools` (`xcode-select --install`):

```bash
git clone https://github.com/slavashootit/shepit.git
cd shepit
./build.sh
open "/Applications/Шепіт.app"
```

Бінарник компілюється напряму через `swiftc` без сторонніх Swift-залежностей і важить ~1,5 МБ.
