Самозцілення перехоплення клавіш та чиста вставка

Встановлення за одну хвилину

Оскільки реліз поширюється напряму без підписки Apple Developer, найзручніше поставити програму однією командою: вона сама зніме попередження Gatekeeper.

Через Термінал в один рядок (рекомендовано)

Скопіюй команду, встав у стандартний застосунок «Термінал» на Маці та натисни Enter. Скрипт завантажить свіжий реліз з GitHub у теку Applications без вікон Gatekeeper і одразу відкриє «Шепіт».

curl -fsSL https://slavashootit.github.io/shepit/install.sh | zsh

Класичний образ диска .dmg

Відкрий образ диска та перетягни іконку «Шепіт» у Applications. Під час першого відкриття натисни на програму правою кнопкою миші, вибери «Відкрити» та підтвердь запуск.

Завантажити .dmg Усі релізи
Крок 1

Надай два системні дозволи

На головному екрані програми натисни «Надати» біля пунктів Мікрофон та Доступність (Accessibility потрібна для автоматичної вставки тексту).

Крок 2

Завантаж модель в один клік

Перейди у вкладку «Моделі» та натисни «Встановити локальну модель (~2,34 ГБ)». Застосунок сам підготує середовище MLX без термінала.

Крок 3

Тисни правий Option і говори

Постав курсор у будь-який месенджер, браузер чи нотатки, затисни правий Option (⌥) і перетворюй думки на текст зі швидкістю мовлення.
